# CC0 instrument samples

The selected files in this directory are used by the browser player. Only a
small subset of each library is included so the page stays reasonably light.

- `emilyguitar/`: Karoryfer Samples Emilyguitar, CC0 1.0.
  Source: https://github.com/sfzinstruments/karoryfer.emilyguitar
  Retained as the legacy guitar bank.
- `freepats-nylon/`: FreePats Spanish Classical Guitar, CC0 1.0.
  Source: https://freepats.zenvoid.org/Guitar/acoustic-guitar.html
  Nine pitch anchors cover the playable guitar range with genuine
  microphone-recorded nylon-string samples.
- `freepats-clean/`: FreePats FSBS Electric Guitar Clean #1, CC0 1.0.
  Source: https://freepats.zenvoid.org/ElectricGuitar/clean-electric-guitar.html
  Thirteen pitch anchors from a sampled Fender-style electric guitar are used
  for clean, crunch, and distorted amplifier profiles.
- `big-little-bass/`: Karoryfer Samples Big Little Bass, CC0 1.0.
  Source: https://github.com/sfzinstruments/karoryfer.big-little-bass
- `vcsl-kawai-piano/`: Versilian Community Sample Library Kawai grand
  piano, CC0 1.0.
  Source: https://github.com/sgossner/VCSL
  Seven sustained-note anchors cover the piano range used by the browser tab.
- `vsco2-strings/`: VSCO 2 Community Edition cello and violin section
  sustains, CC0 1.0.
  Source: https://github.com/sgossner/VSCO-2-CE
  Seven pitch anchors cover the detected orchestral/string range.
- `virtuosity-drums/`: Virtuosity Drums by Versilian Studios and Karoryfer
  Samples, CC0 1.0.
  Source: https://github.com/sfzinstruments/virtuosity_drums
  The `natural/` subset uses kick/snare close microphones, cymbal overheads,
  and mid microphones for high/low toms. Multiple dynamics and alternate hits
  are included to reduce repetitive machine-gun playback.

The source libraries' CC0 license permits commercial and non-commercial use.
This notice documents provenance; attribution is not required by CC0.
The piano and string browser subsets were transcoded to 44.1 kHz, 96 kbps MP3
and trimmed to a maximum of six seconds for practical web delivery.
